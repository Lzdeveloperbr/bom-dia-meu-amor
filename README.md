# Bom dia, meu amor ❤️

Uma página romântica, responsiva e com pequenos efeitos cinematográficos, criada especialmente para Andressa.

## Acessar o site

Depois que o GitHub Pages concluir a publicação, o site ficará disponível em:
https://lzdeveloperbr.github.io/bom-dia-meu-amor/

## Publicação

O repositório está configurado para publicar automaticamente pelo GitHub Actions sempre que houver atualização na branch `main`.

## Personalização

Edite os textos diretamente no `index.html`. As fontes são carregadas do Google Fonts; sem conexão, o navegador usa fontes de fallback.

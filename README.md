# Bom dia, meu amor ❤️

Experiência romântica criada especialmente para Andressa. Site estático, responsivo e publicado pelo GitHub Pages.

## Sites
- **Bom dia:** https://lzdeveloperbr.github.io/bom-dia-meu-amor/
- **Boa noite:** https://lzdeveloperbr.github.io/bom-dia-meu-amor/boa-noite.html

## Experiência de bom dia
- Abertura cinematográfica, céu estrelado, partículas e animações delicadas.
- Rosa interativa, jardim onde é possível plantar e regar flores.
- Música do YouTube com tentativa de reprodução automática (o navegador pode exigir um toque para liberar o som).
- Carta romântica e contador desde **17/11/2024**.
- Linha do tempo, mensagens diárias, abraço virtual e oração.
- Poção de carinho com mensagens mágicas diferentes.
- Galeria para adicionar até 6 fotos diretamente pelo celular.
- Fotos adicionadas ficam armazenadas localmente no navegador/aparelho; não são enviadas ao GitHub nem a um servidor.
- Botão para compartilhar o link do site.
- Barra de progresso de leitura, atalhos flutuantes e layout adaptado para celular e desktop.
- Respeito à preferência do sistema por movimento reduzido.

## Nova experiência de boa noite
A página `boa-noite.html` é uma experiência noturna independente, com:
- Céu estrelado animado, lua interativa e visual noturno responsivo.
- Carta personalizada para Andressa, com referência ao início do relacionamento em **17/11/2024**.
- Exercício opcional de respiração guiada para desacelerar antes de dormir.
- Oração inspirada no Salmo 4:8.
- Abraço virtual, beijo de boa noite e chuva delicada de corações.
- Manifesto PWA, ícone próprio e cache básico para reabrir a página quando estiver offline depois da primeira visita.

### Instalar no celular
1. Abra o link **Boa noite** no Chrome.
2. Toque no menu de três pontinhos.
3. Escolha **Instalar app** ou **Adicionar à tela inicial** (o texto pode variar).
4. Confirme. O ícone e o nome “Boa noite ♡” serão usados quando o navegador oferecer suporte à instalação.

O PWA e o cache offline dependem de o site estar publicado em HTTPS pelo GitHub Pages. A página não força reprodução de música: navegadores móveis normalmente bloqueiam áudio automático sem interação.

## Como adicionar fotos na página de bom dia
1. Abra o site no aparelho em que deseja guardar as fotos.
2. Vá até **Memórias** e toque em **Adicionar nossas fotos**.
3. Escolha até 6 imagens. Elas serão redimensionadas e guardadas no armazenamento local do navegador.
4. Para remover uma imagem, toque no **×** sobre ela. O botão **Limpar fotos adicionadas** limpa toda a galeria local.

As fotos ficam salvas apenas naquele navegador e aparelho. Se limpar os dados do navegador ou trocar de aparelho, será necessário adicioná-las novamente.

## Personalização
O conteúdo de bom dia está em `index.html`; a experiência noturna está em `boa-noite.html`. A data do relacionamento está definida em cada página como **17/11/2024**.
